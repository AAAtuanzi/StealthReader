# 工作党✖️小说妹的双重狂喜

<img src="Resources/AppIcon.png" alt="StealthReader 图标" width="112">

一个轻量的 macOS 本地 TXT 阅读器。窗口自由缩放，鼠标移开后，留下无边缘阅读器；完美融入工作文档，老板站我身后都不怕！

使用 **SwiftUI + AppKit** 编写，无第三方运行依赖，无需账号，不上传书籍。

当前版本：**1.14.1** · 系统要求：**macOS 13 或更高版本**

## 下载与安装

1. [下载 v1.14.1 App 压缩包](downloads/StealthReader-macOS-arm64-v1.14.1.zip?raw=true)（Apple Silicon / arm64）。
2. 解压得到 `StealthReader.app`，放到“应用程序”或其他固定目录。
3. 打开 App，按 `⌘O` 选择本地 TXT 文件。
4. 如需固定入口，将这份 App 拖到屏幕底部的应用栏，之后从同一个图标打开。

当前安装包适用于 **Apple Silicon（M 系列芯片）Mac**，压缩包约 1 MB。Intel Mac 可尝试在本机从源码编译；当前没有提供已验证的 Intel 安装包。

> 安装包使用本机临时签名，未经过 Apple 公证。首次打开时，macOS 可能提示无法验证开发者。请确认文件来自本仓库；也可以按下方说明自行编译。不要为此关闭系统整体安全保护。

下载文件的 SHA-256 校验值见 [SHA256SUMS.txt](downloads/SHA256SUMS.txt)。

## 如何使用

- **显示操作区**：鼠标悬停在窗口左上角；仅移到正文其他位置不会唤出控件。
- **收起操作区**：鼠标离开顶部控制区后，标题栏、边框、阴影、滚动条和按钮自动隐藏，正文仍然显示。
- **调整窗口**：拖动窗口边缘缩放。最窄约为当前字号下的 6 个汉字，最小高度为 44 点；字号较小时可作为一行阅读条使用。
- **移动窗口**：唤出操作区后拖动标题栏。
- **切换配色**：点击半黑半白图标，在小菜单中预览底色和字色，再点击选择；不会一点击图标就立即切换。
- **窄窗口操作**：控件自动收进“…”菜单，打开、搜索、字号、配色仍可使用。
- **搜索文字**：按 `⌘F`，输入文字或短语，使用上一个、下一个结果定位正文。
- **继续阅读**：再次启动时自动打开上一本书，并按文件记录的字符位置恢复阅读。移动或删除原 TXT 文件后，需要重新选择文件。

菜单展开或选择文件期间暂时停止自动隐藏，方便操作。

## 功能

- 本地 TXT 阅读，支持 UTF-8、带字节顺序标记的 UTF-16、GBK / GB18030、Big5 编码。
- 窗口自由缩放，正文左右不添加额外留白。
- 字号可在 10–48 点之间调整，并自动保存。
- 六套配色，支持预览、直接选择和快捷键循环切换。
- 文字可选择、复制，支持原生搜索和匹配定位。
- 按文件保存阅读位置，重新打开时恢复进度。
- 后台读取文本，使用原生长文本视图排版。
- 顶部菜单栏的应用名称留空，保留“文件、编辑、显示、阅读、窗口、帮助”和常用快捷键；App 文件名及图标不变。

隐藏的是窗口控件，不是正文。它不是隐藏进程、阻止截图或防止录屏的工具。

| 白色 | 白色 | 深灰 | 宋体 |

白色、深灰、深蓝灰、浅雾白共用普通字号设置，首次使用默认 18 点。石墨灰和深靛灰分别记忆字号，默认分别为 20 点和 24 点；这两套样式保留抗锯齿、关闭额外的字体平滑加厚。

## 快捷键

| 快捷键 | 操作 |
| --- | --- |
| `⌘O` | 打开 TXT |
| `⌘F` | 搜索文字 |
| `⌘+` / `⌘-` | 增大 / 减小字号 |
| `⌘/` | 循环切换配色 |
| `⌘H` | 隐藏整个阅读器 |
| `⌘Q` | 完全退出阅读器 |

## 从源码运行

需要 macOS 13+，并安装支持 Swift 5.9 或更高版本的 Xcode / Xcode Command Line Tools。

```bash
git clone https://github.com/AAAtuanzi/StealthReader.git
cd StealthReader
swift run
```

如果终端提示需要同意 Xcode 许可协议，请先自行打开 Xcode，阅读并完成初始化，再继续编译。

## 打包为 App

在项目目录中运行：

```bash
zsh scripts/build-app.sh
```

脚本会编译程序、复制图标、进行临时签名并检查安装包，生成：

```text
StealthReader.app
StealthReader-macOS-arm64-v1.14.1.zip
```

架构由运行打包脚本的 Mac 决定；Intel Mac 上生成的压缩包名使用 `x86_64`。编译缓存位于系统临时目录，不会打入 App 或 ZIP。

打包脚本会更新项目目录中已有的 `StealthReader.app`，建议先退出阅读器再执行。

## 更新方式

目前没有联网自动更新功能。下载新版后，先按 `⌘Q` 完全退出，再用新版替换固定目录中的 App，然后从原入口打开。

配色、字号、上次打开的文件路径和阅读位置保存在本机用户偏好设置中，不在 App 安装包内；保留相同应用标识更新时可继续使用这些设置。

## 项目结构

```text
Package.swift                    Swift Package 配置
Sources/StealthReader/           窗口、阅读、搜索、配色及本地状态
Resources/                      应用图标及 Info.plist
downloads/                      当前版本 App 压缩包及校验值
scripts/build-app.sh             App 打包脚本
scripts/verify-*.swift           菜单、配色、排版及最小窗口测试
```

仓库不收录展开后的 App、历史 ZIP、编译缓存和本机文件记录。`downloads/` 只保留当前版本的 App 压缩包；只想使用阅读器时，下载上方约 1 MB 的 App 文件即可，不需要下载整个仓库。

## 隐私与反馈

阅读器在本机读取文件和保存设置，不包含账号登录、书籍上传、广告或使用统计。请自行准备有权使用的 TXT 文件。

当前是轻量 TXT 阅读器，不支持 EPUB / PDF、云同步、书城或跨设备进度同步。超大文本的实际流畅度取决于文件与设备；恢复阅读时会定位到已保存字符附近，不保证逐像素复原滚动位置。

如遇到乱码、缩放或搜索问题，可在 [Issues](https://github.com/AAAtuanzi/StealthReader/issues) 中反馈系统版本、芯片类型、App 版本及复现步骤。请不要上传含有个人信息或无权公开的整本小说。
